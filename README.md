## About

A small fan-made chat app where you can talk with Monika from *Doki Doki Literature Club!*, powered by Google's Gemini API.

👉 **Try it live:** [monika.kyokai.me](https://monika.kyokai.me)

- 🔑 Bring your own Gemini API key (BYOK), no key is bundled
- 🔒 Your chats are never stored on a server, they are only sent to Gemini
- ⚡ Runs entirely in your browser, no backend needed

## Run locally

Requires Node.js 18 or newer.

```bash
git clone https://github.com/kyoyacchi/monika-chat.git
cd monika-chat
npm install
npm run dev
```

Open the local URL Vite prints, click **API key**, and paste a free key from [Google AI Studio](https://aistudio.google.com/apikey). Your key stays in your browser's `localStorage`.
